# Coursework asset attribution

The project author created the URDF and coordinate-frame definitions using SolidWorks.
The CAD assets used for the robot meshes were supplied by the university for the coursework.
This project is being prepared for coursework evaluation.

The earlier `LicenseRef-Vendor-CAD-Restricted` package label was not based on verified
licensing terms and has been replaced with `LicenseRef-Unspecified`. This records that
no specific license has been established here; it does not assert a vendor restriction
or grant a blanket open-source license to the supplied assets. Existing upstream notices,
if supplied with the assets, should be retained.
